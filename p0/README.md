# DaurenBOT v11 — P0, встроенный Node.js и Baileys

## Статус
Это **первый экспериментальный APK**, а не завершённая версия DaurenBOT v11. Он предназначен для проверки возможности одного APK **без Termux** на Xiaomi 12T Pro.

**Реализовано в исходном коде:** Node.js 24 LTS как нативный `libnode.so` ARM64 через JNI, Android foreground service (`remoteMessaging`), sandbox-хранилище, Baileys, pairing-code flow, отслеживание количества входящих сообщений без хранения текста, ручная тестовая отправка только с подтверждением, локальный Unix-сокет 0600. Автоматические ответы и служебные доклады отключены.

**НЕ реализовано / НЕ проверено:** фактический запуск на Xiaomi, same-phone pairing, доставка сообщения на устройство получателя, шифрование файлов WhatsApp-сессии в Android Keystore, сохранение всех функций v10.1, работа в фоне 24/7. База `useMultiFileAuthState` из Baileys для прототипа хранит ключи в изолированной директории приложения, но **не шифрует их**: не привязывай личный/служебный аккаунт до устранения этого ограничения.

## Сборка
Workflow `.github/workflows/v11-p0.yml` на ветке `v11-p0-embedded-node` скачивает предсобранный Android Node.js 24.22.1-0 из проекта `fogtape/nodejs-mobile`, проверяет SHA-256, упаковывает `node_modules` и JS внутри APK, компилирует JNI и публикует тестовый APK как GitHub Actions artifact. Node runtime никогда не скачивается на телефоне после установки; он уже включён в APK.

### Тест на Xiaomi 12T Pro

1. Установи APK из успешной сборки GitHub Actions. Для P0 используй **отдельный тестовый WhatsApp-номер**.
2. Нажми **«Запустить встроенный движок»**, затем **«Статус»**. Ожидается `node: v24.22.1`, `webSocket: true`, `crypto: true`, `tls: true`, `stage: ready`.
3. Введи тестовый номер, нажми **«Запросить код»** и проверь наличие `pairingCode`.
4. Проверь, принимает ли официальный WhatsApp привязку связанного устройства **на этом же телефоне**. Если не принимает — зафиксировать ограничение.
5. Отправь боту сообщение с другого номера, затем обнови статус. Должен увеличиться `incomingCount` и появиться `lastIncomingType: private`.
6. Для проверки исходящей отправки вручную введи тестового получателя и текст, подтверди отправку. Статус `submittedId` означает только принятие в библиотеке, **не доставку**.

### Критерий P0
Нельзя объявлять проект полноценным до фактической привязки и двусторонней связи на Xiaomi. Следующая очередь работ: защищённое хранилище Baileys, интеграция команд/ИИ/памяти v10.1, Kotlin Compose UI, фоновые сценарии/отказы, E2E, подпись release.

## Ограничения и источники
Baileys неофициален; WhatsApp может ограничить аккаунт. Автопилот и команды специально отключены в P0, чтобы не вмешиваться в личную/служебную переписку. Сторонний мобильный Node.js требует независимого аудита поставки/бинарника перед релизом.

- Node Android lib: https://github.com/fogtape/nodejs-mobile/releases/tag/v24.22.1-0
- Baileys: https://github.com/WhiskeySockets/Baileys
- Android FGS: https://developer.android.com/develop/background-work/services/fgs
