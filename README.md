# DaurenBOT Android — Notification Edition

**APK собран успешно в GitHub Actions.** Приложение предназначено для Xiaomi 12T Pro и других телефонов Android 8.0+.

## Скачать APK

1. [Открыть успешную сборку](https://github.com/rufus1981vlom-ship-it/DaurenBOT-Android/actions/runs/42552784432)
2. Внизу страницы, в разделе **Artifacts**, нажать **DaurenBOT-Android-APK** (для скачивания может потребоваться вход в GitHub).
3. Распаковать ZIP и установить файл **app-debug.apk** на Android.
4. Открыть DaurenBOT → **Доступ к уведомлениям** → разрешить доступ, ввести **новый** ключ DeepSeek → указать исключения → включить автоответ.

### Возможности и ограничения

Это **экспериментальный Android-автоответчик через уведомления WhatsApp**, а НЕ полноценный DaurenBOT v9.1.9/v10 (Baileys). Доступны настройки DeepSeek, шифрование ключа через Android Keystore, исключения по отображаемому имени и ручная пауза на минуту. Ответ возможен только если уведомление WhatsApp содержит действие **Ответить**.

**Не реализованы:** `!chat scan`, голосовые, команды внутри WhatsApp, исходящие расписания, сопоставление `@lid` с номером и автоматическое обнаружение ручного ответа владельца. Уведомления не позволяют достоверно установить номер или тип чата: защита командования и групп не гарантирована. **Не включайте автоответ на служебном аккаунте; сперва протестируйте на отдельном номере.**

GitHub Actions используется только для сборки APK. После установки приложение работает на телефоне без компьютера или сервера, но DeepSeek требует интернет и действующий API-ключ. На HyperOS необходимо разрешить уведомления WhatsApp и работу приложения без ограничений батареи.

**Безопасность:** код находится в публичном репозитории, но не содержит API-ключей и WhatsApp-сессий. Ранее опубликованные ключи следует отозвать и заменить. Сообщения, на которые отвечает ИИ, передаются DeepSeek через сеть.
