# DaurenBOT Android — Notification Edition

Экспериментальное Android-приложение для ИИ-ответов на **входящие уведомления WhatsApp** через DeepSeek. Работает на телефоне без компьютера или собственного сервера, но требует интернета и API-ключа DeepSeek.

**Ограничения:** это НЕ полноценная мобильная версия DaurenBOT v9.1.9/v10. Android не предоставляет стороннему приложению полный доступ к чатам WhatsApp: команды `!chat scan`, голосовые, расписания и сопоставление `@lid` с номером не поддерживаются. Ответ возможен только при наличии у уведомления WhatsApp действия «Ответить». Надёжно определить группы и командование по уведомлению невозможно; сначала используйте тестовый аккаунт.

## Получение APK с телефона

Открой [Actions](https://github.com/rufus1981vlom-ship-it/DaurenBOT-Android/actions), выбери **Build DaurenBOT APK**, дождись успешной сборки и скачай артефакт **DaurenBOT-Android-APK**. В нём будет файл `app-debug.apk`.

Архив `android-source.zip` содержит исходники Gradle/Java. GitHub Actions распаковывает его перед сборкой.

## Настройка

После установки разреши доступ к уведомлениям, введи **новый** ключ DeepSeek, настрой исключения и включи автоответ. На Xiaomi разреши приложению работу без энергосбережения и проверь работу на тестовом номере.

**Безопасность:** не публикуй API-ключи и WhatsApp-сессии в GitHub. Ранее раскрытые ключи нужно отозвать и заменить.

Приложение не является официальным продуктом WhatsApp, DeepSeek или OpenAI.
