# DaurenBOT Android — Mobile Control v1.1.0

**Скачать настоящий APK:** [DaurenBOT-Mobile-Control.apk](https://github.com/rufus1981vlom-ship-it/DaurenBOT-Android/releases/download/v1.1.0/DaurenBOT-Mobile-Control.apk)

APK — **панель для полноценного DaurenBOT, работающего локально в Termux на этом же телефоне**. Это не автономный WhatsApp-клиент: один APK без Baileys-движка в Termux не отвечает на сообщения. Внешний компьютер или сервер не нужны; DeepSeek требует интернет.

## Два компонента

1. Установите **Termux из F-Droid**, запустите DaurenBOT Android Termux v10.1 из архивного комплекта, предоставленного вместе с APK. Он хранит сессию и управляет WhatsApp через Baileys.
2. Установите APK по прямой ссылке выше. На Xiaomi откройте Termux и выполните `cat ~/DaurenBOT_Android/data/control-token`. Вставьте полученный 64-символьный токен в APK, нажмите **Проверить связь**.

Локальная панель связывается только с `127.0.0.1:16619` и требует ключа. Не вводите ключ DeepSeek в GitHub. На Android разрешите Termux работу без ограничений батареи. Для автозапуска — Termux:Boot.

## Возможности

Движок v10.1 на основе ядра v9.1.9 содержит: DeepSeek, память, автоответы личным контактам, короткие и длинные WhatsApp-команды, правила, расписания, групповые доклады с явным подтверждением, черновики, журнал, голосовые через STT при настройке, блокировки командования, ручной перехват на 1 минуту и осторожное сопоставление @lid с номером. На APK доступны: статус и пауза, контакты, защита руководства, ИИ, промпты, голосовая настройка, списки чатов, память, правила, расписания, черновики, отчёты и использование ИИ. Остальные функции управляются из «Сообщения себе» через `!`, `!help` и старые команды.

**Ограничения:** `!chat scan` использует только кэш синхронизированных чатов Baileys, а не гарантированно весь WhatsApp. Движок неофициальный и может перестать работать после изменения WhatsApp или вызвать ограничение аккаунта. Его реальная установка и привязка на Xiaomi не проверены; 16 локальных тестов проверяют логику без живой сети. До испытаний не используйте с рабочими/служебными чатами и не оставляйте пустым список командования.
